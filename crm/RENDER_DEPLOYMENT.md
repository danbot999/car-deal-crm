# Render Deployment Notes

This app can be deployed as a Render Free web service and will receive a public
`*.onrender.com` URL after the service is created.

## Important

- The current CRM is local-first and uses SQLite.
- Render Free web services have an ephemeral filesystem, so local SQLite data is
  not durable on the free web service.
- The local `.env`, SQLite database, and cached listing images are intentionally
  ignored and should not be pushed as public deployment data.
- The current app has no login. Do not publish a real private CRM publicly until
  authentication is added.

## Render Blueprint

The repository root now includes `render.yaml`.

Render settings from the blueprint:

- Service type: Web Service
- Plan: Free
- Root directory: `crm`
- Build command: `npm ci && npm run prisma:generate && npm run build`
- Start command: `npm run start:render`
- Auto deploy trigger: every commit
- Default public URL: generated by Render as `https://<service-name>.onrender.com`

## Recommended Production Path

For a real hosted CRM:

1. Add a simple password/login gate.
2. Move the database from local SQLite to hosted Postgres.
3. Move the n8n-to-CRM sync to the hosted API.
4. Deploy on Render and keep the `*.onrender.com` URL, or attach a custom domain.
